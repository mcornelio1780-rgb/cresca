Cómo publicar la web y el panel de Cresca

Unos 15 minutos, una sola vez. Todo es gratis y se hace desde el navegador: no necesitas programar ni tarjeta de crédito.

1. GitHub2. Subir archivos3. Vercel4. Token de GitHub5. Conectar el panel6. Prueba finalSi algo falla

1Crear el repositorio en GitHub

3 minutos

Un repositorio es una carpeta en internet donde vive tu web. El panel guarda ahí los cambios.

  1. Entra a github.com e inicia sesión. Si no tienes cuenta, pulsa Sign up y créala con tu correo.
  2. Arriba a la derecha pulsa el botón + y elige New repository.
  3. En Repository name escribe cresca-web.
  4. Deja marcado Public (público). Tu web la publica Vercel y es visible para todos, sea Public o Private: esa opción solo decide quién ve el código en GitHub. El panel tiene su propia contraseña.
  5. Pulsa Create repository.

2Subir los archivos

3 minutos

  1. Descomprime el zip en tu computadora. Verás la carpeta cresca-web.
  2. En la página del repositorio recién creado, pulsa el enlace uploading an existing file.
  3. Abre la carpeta cresca-web en tu computadora, selecciona todo lo que hay dentro (incluida la carpeta api) y arrástralo a la página de GitHub.
  4. Espera a que termine de cargar y pulsa Commit changes.
Sube el contenido de la carpeta, no la carpeta entera: en la raíz del repositorio deben quedar index.html, panel.html, content.json, vercel.json y la carpeta api.

3Publicar en Vercel

3 minutos

  1. Entra a vercel.com y pulsa Sign up → Continue with GitHub. Acepta los permisos.
  2. Pulsa Add New… → Project.
  3. En la lista aparece cresca-web. Pulsa Import. Si no aparece, pulsa Adjust GitHub App Permissions y dale acceso a ese repositorio.
  4. En Framework Preset deja Other. No cambies nada más.
  5. Pulsa Deploy. En menos de un minuto verás confeti y tu web publicada, con una dirección como cresca-web.vercel.app.
Más adelante puedes conectar tu propio dominio en Vercel → tu proyecto → Settings → Domains.

4Crear el token de GitHub (para que el panel pueda guardar)

4 minutos

El token es un permiso que le das al panel para escribir solo en el repositorio cresca-web.

  1. En GitHub, pulsa tu foto (arriba a la derecha) → Settings.
  2. Al final del menú izquierdo pulsa Developer settings.
  3. Pulsa Personal access tokens → Fine-grained tokens → Generate new token.
  4. Token name: cresca-panel. Expiration: elige 1 año (o Custom con la fecha que prefieras).
  5. Repository access: marca Only select repositories y elige cresca-web.
  6. En Permissions → Repository permissions, busca Contents y cámbialo a Read and write. (Metadata queda en Read-only solo; está bien.)
  7. Baja y pulsa Generate token. Copia el token (empieza con github_pat_). Solo se muestra una vez.
Cuando el token venza, repite este paso y pega el nuevo en el panel.

2 minutos

  1. Abre tu web, baja hasta el footer y pulsa Panel (o entra directo a tu-web.vercel.app/panel.html). Escribe la contraseña 1789.
  2. Ve a Ajustes y completa:

  3. Pulsa Cargar desde GitHub. Debe aparecer «Contenido cargado desde GitHub».
  4. En la misma pantalla revisa el número de WhatsApp (51995422760) y el enlace de Cal.com.
Estos datos se guardan solo en tu navegador. Si usas otra computadora, repite este paso.

6Prueba final

2 minutos

  1. En el panel, ve a Portafolio, edita un proyecto y cambia algo pequeño.
  2. Pulsa Listo y luego Guardar y publicar.
  3. Espera un minuto y recarga tu web: el cambio ya está publicado.
  4. En la web, llena el formulario «Hablemos»: se abre WhatsApp con el mensaje listo para enviarte.
